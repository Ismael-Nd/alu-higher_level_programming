# python-input_output

This project covers reading and writing text files, JSON
serialization/deserialization, converting simple objects to and from
JSON-compatible dictionaries, and a classic whiteboard exercise
(Pascal's Triangle).

## Tasks

| File | Description |
| --- | --- |
| 0-read_file.py | Reads a text file (UTF8) and prints it to stdout |
| 1-write_file.py | Writes a string to a text file, returns chars written |
| 2-append_write.py | Appends a string to a text file, returns chars added |
| 3-to_json_string.py | Returns the JSON representation of an object |
| 4-from_json_string.py | Returns an object represented by a JSON string |
| 5-save_to_json_file.py | Writes an object to a text file using JSON |
| 6-load_from_json_file.py | Creates an object from a JSON file |
| 7-add_item.py | Adds all arguments to a list and saves it to `add_item.json` |
| 8-class_to_json.py | Returns the dictionary description of a simple object |
| 9-student.py | `Student` class with a `to_json()` method |
| 10-student.py | `Student` class with a filterable `to_json(attrs=None)` |
| 11-student.py | `Student` class with `to_json()` and `reload_from_json()` |
| 12-pascal_triangle.py | Returns a list of lists representing Pascal's Triangle |
